
ต้องการให้ออกแบบ dev plugin  สำหรับพัฒนาระบบ web , api, mobile

  - การพัฒนา Code รองรับหลาย framework เช่น .net , vue, next.js , ...  . 
  - การกำหนด file structure 
  - การเรียกใช้ skill ให้ถูกต้อง เช่น ถ้าเป็น .net เรียก dotnet-dev  , ถ้าเป็น next.js เรียก vercel best pratric skill, ถ้าออกแบบหน้าเวป html ให้เรียก frontend design skill. แนะนำให้ถามจากผู้สั่งงานก่อน และเขียนเก็บเป็นความจำ เนื่องจาก  project พัฒนาไม่เหมือนกัน
  - ต้องอ่านว่าใช้ server อะไร, database อะไร และมี tool อะไรเพิ่มเติมหรือไม่ เช่น redis , rabbitMQ เป็นต้น
  - การทดสอบ deploy บน docker เขียน docker compose , โครงสร้างควรเป็น root/docker/docker-compose , docker file อยู่ภายใต้ project ของ web หรือ api
  - สามารถเริ่มพัฒนาระบบ โดย มี หรือ ไม่มี mockup ที่ได้จาก mockup plugin ได้
  - ต้องเชื่อมโยงข้อมูล ตรวจสอบย้อนกลับ และ รู้ว่าหน้าเวป หรือ code มาจาก req ,design ,logic, mockup อะไร
  - ทำ unit test 
  - ต้องมี help command
