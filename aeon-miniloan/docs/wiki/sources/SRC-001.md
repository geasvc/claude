## ที่สกัดออกมา (markdown-text)

> §5 กฎธุรกิจ (Business Rules) — ค่าสมมติทั้งหมด · BR-01 คุณสมบัติผู้สมัคร: อายุ 20–60 ปี / รายได้ต่อเดือน ≥ 15,000 บาท / อายุงานปัจจุบัน ≥ 4 เดือน · BR-02 ความสามารถในการชำระ (DTI): Debt-to-Income หลังรวมงวดใหม่ ต้อง ≤ 70% ของรายได้ต่อเดือน, DTI = (ภาระหนี้เดิมต่อเดือน + งวดใหม่โดยประมาณ) / รายได้ต่อเดือน · BR-03 วงเงินสูงสุด: วงเงินอนุมัติสูงสุด = 5 เท่าของรายได้ต่อเดือน และไม่เกิน 1,000,000 บาท · BR-04 เงื่อนไขสินเชื่อ: จำนวนเงินกู้ 10,000 – 1,000,000 บาท / จำนวนงวด 6 – 60 งวด (รายเดือน) / อัตราดอกเบี้ยแบบลดต้นลดดอก 25% ต่อปี · BR-05 การให้คะแนน (Credit Band): Band A ผ่านทุกเกณฑ์ + DTI ≤ 50% / Band B ผ่านเกณฑ์ + DTI 50–70% / Band C ผิดเกณฑ์ข้อใดข้อหนึ่ง → ปฏิเสธพร้อมเหตุผล · BR-06 การคำนวณงวดผ่อน (Amortization): EMI = P × r × (1+r)^n / ((1+r)^n − 1), แต่ละงวดแยกเป็นดอกเบี้ย (ยอดคงเหลือ × r) และเงินต้น (EMI − ดอกเบี้ย), งวดสุดท้ายปัดเศษให้ยอดคงเหลือเป็น 0 พอดี · BR-07 การปิดก่อนกำหนด: ยอดปิดบัญชี = เงินต้นคงเหลือ + ดอกเบี้ยค้างจ่ายถึงวันที่ปิด + ค่าธรรมเนียมปิดก่อนกำหนด (สมมติ 1% ของเงินต้นคงเหลือ), ดอกเบี้ยของงวดในอนาคตที่ยังไม่ถึงกำหนดไม่คิด — ส่วนที่เหลือของไฟล์ (§1–§4, §6–§10) อ่านจากไฟล์ต้นทางโดยตรง ไม่ทำสำเนา
