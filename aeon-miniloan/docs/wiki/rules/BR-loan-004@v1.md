# BR-loan-004@v1

## ข้อความของกฎ
ผู้สมัครต้องผ่านคุณสมบัติครบทั้งสามข้อ: อายุ 20–60 ปี · รายได้ต่อเดือน ≥ 15,000 บาท · อายุงานปัจจุบัน ≥ 4 เดือน · ผิดข้อใดข้อหนึ่งได้ Band C พร้อมเหตุผล

## ที่มา

> "อายุ 20–60 ปี"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§5 BR-01 คุณสมบัติผู้สมัคร

> "รายได้ต่อเดือน ≥ 15,000 บาท"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§5 BR-01 คุณสมบัติผู้สมัคร

> "อายุงานปัจจุบัน ≥ 4 เดือน"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§5 BR-01 คุณสมบัติผู้สมัคร

> "**Given** ผิด BR-01 (คุณสมบัติ) **When** ประเมิน **Then** ได้ Band C พร้อมเหตุผล และสถานะใบสมัครพร้อมถูกปฏิเสธ"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§7 US-03
