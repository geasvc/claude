# BR-loan-024@v1

## ข้อความของกฎ
Applicant เรียกใช้การกระทำที่เปลี่ยนสถานะแบบย้อนกลับไม่ได้ — อนุมัติ ปฏิเสธ เบิกจ่าย บันทึกชำระ และปิดบัญชี — ไม่ได้ ทั้งห้าอย่างเป็นสิทธิ์ของเจ้าหน้าที่เท่านั้น (Loan Officer หรือ Operations ตามที่ REQ นั้นกำหนด) · API ต้องปฏิเสธคำขอจาก Applicant ทุกกรณี ไม่พึ่งการซ่อนปุ่มที่ Web · สิ่งที่ Applicant ทำได้คือ กรอกร่าง ยื่นใบสมัคร ดูสถานะ ดูตารางผ่อนของบัญชีตัวเอง และขอยอดปิดบัญชี

## ที่มา

> "**Applicant** | ผู้สมัครสินเชื่อ กรอกและยื่นใบสมัคร ดูสถานะ"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§3 ผู้ใช้งาน (Actors)

> "**Operations** | บันทึกการชำระเงิน และดำเนินการปิดบัญชี"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§3 ผู้ใช้งาน (Actors)

> "Applicant เดินสถานะได้ขั้นเดียวคือยื่นใบสมัคร ขั้นที่เหลือเป็นของ Loan Officer และ Operations"
> — [SRC-002](../sources/SRC-002.md) หน้า — §QB-actor-02 + QB-perm-01
