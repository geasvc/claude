# BR-loan-005@v1

## ข้อความของกฎ
อัตราส่วนภาระหนี้ต่อรายได้หลังรวมค่างวดใหม่ต้อง ≤ 70% ของรายได้ต่อเดือน โดย DTI = (ภาระหนี้เดิมต่อเดือน + ค่างวดใหม่) / รายได้ต่อเดือน · DTI > 70% ได้ Band C

## ที่มา

> "Debt-to-Income หลังรวมงวดใหม่ ต้อง ≤ 70% ของรายได้ต่อเดือน"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§5 BR-02 ความสามารถในการชำระ (DTI)

> "สูตร: `DTI = (ภาระหนี้เดิมต่อเดือน + งวดใหม่โดยประมาณ) / รายได้ต่อเดือน`"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§5 BR-02 ความสามารถในการชำระ (DTI)

> "**Given** DTI > 70% (BR-02) **When** ประเมิน **Then** ได้ Band C"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§7 US-03
