
ต้องการให้ออกแบบ qa plugin  สำหรับออกแบบหน้าจอ

  - ออกแบบ scenario , test case , workflow test, data test, ui test และอื่นๆ ที่ qa ต้องทำ
  - สามารถให้ user ถามได้ เช่น หน้าจอนี้ ทดสอบอะไรบ้าง มีข้อมูลอะไร มี workflow อะไรเกี่ยวข้อง
  - สั่งทดสอบ โดยให้ capture screen ได้ และต้องเก็บรูปภายใต้ qa/ folder และต้องแยกรูปเป็นหมวดหมู่
  – เขียนรายงานทดสอบได้ เลือก module หรือ หน้าจอ ที่ต้องการให้รายงาน
  - ให้สามารถดูประวัติการทดสอบได้ 
  - สร้าง project test ให้รองรับ .net , next.js , python และอื่นๆ 
  - ให้เลือก tool สำหรับทดสอบได้ เช่น playwright , popertear, claude in chrome 
  - เชื่อมโยงกับ design skill, dev skill ได้
  - ขอให้คุณ fable แนะนำเพิ่มเติมได้ เพราะผมไม่ถนัด qa, ควรมีอะไรเพิ่มเติมอีกบ้าง
  - ต้องเชื่อมโยงข้อมูล ตรวจสอบย้อนกลับ และ รู้ว่าหน้า test  มาจาก req ,design ,logic, mockup อะไร
  - ต้องมี help command
