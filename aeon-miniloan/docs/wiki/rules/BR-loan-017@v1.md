# BR-loan-017@v1

## ข้อความของกฎ
แต่ละงวดแยกเป็นดอกเบี้ย (ยอดคงเหลือ × r) และเงินต้น (EMI − ดอกเบี้ย) · ผลรวมเงินต้นทุกงวดต้องเท่ากับเงินต้นตั้งต้นพอดี โดยงวดสุดท้ายเป็นตัวรับเศษ · ยอดคงเหลือหลังงวดสุดท้ายต้องเท่ากับ 0

## ที่มา

> "แต่ละงวดแยกเป็นดอกเบี้ย (ยอดคงเหลือ × r) และเงินต้น (EMI − ดอกเบี้ย)"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§5 BR-06 การคำนวณงวดผ่อน

> "งวดสุดท้ายปัดเศษให้ยอดคงเหลือเป็น 0 พอดี"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§5 BR-06 การคำนวณงวดผ่อน

> "**Given** ตารางถูกสร้าง **When** รวมเงินต้นทุกงวด **Then** เท่ากับเงินต้นตั้งต้นพอดี (งวดสุดท้ายปัดเศษ)"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§7 US-08
