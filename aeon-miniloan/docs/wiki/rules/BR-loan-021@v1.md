# BR-loan-021@v1

## ข้อความของกฎ
ยอดปิดบัญชีก่อนกำหนด = เงินต้นคงเหลือ + ดอกเบี้ยค้างจ่ายถึงวันที่ปิด + ค่าธรรมเนียมปิดก่อนกำหนด 1% ของเงินต้นคงเหลือ · ไม่คิดดอกเบี้ยของงวดในอนาคตที่ยังไม่ถึงกำหนด

## ที่มา

> "ยอดปิดบัญชี = เงินต้นคงเหลือ + ดอกเบี้ยค้างจ่ายถึงวันที่ปิด + ค่าธรรมเนียมปิดก่อนกำหนด (สมมติ 1% ของเงินต้นคงเหลือ)"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§5 BR-07 การปิดก่อนกำหนด

> "ดอกเบี้ยของงวดในอนาคตที่ยังไม่ถึงกำหนด **ไม่คิด**"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§5 BR-07 การปิดก่อนกำหนด
