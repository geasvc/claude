# REQ-loan-002

## เป้าหมาย
ประเมินใบสมัครตามกฎที่กำหนด แล้วออกผลการประเมินที่มีคะแนน ระดับเครดิต วงเงินที่อนุมัติได้ และเหตุผลรายเกณฑ์

**actor:** System · **ความสำคัญ:** high · **มีหน้าจอ:** ไม่

## คุณค่าทางธุรกิจ
เจ้าหน้าที่ตัดสินใจบนเกณฑ์ชุดเดียวกันทุกใบ และปฏิเสธใบที่ผิดเกณฑ์ได้โดยไม่ต้องคำนวณเอง

## กฎที่ยังใช้อยู่

| กฎ | ชนิด | ข้อความ | ตัวอย่าง |
|---|---|---|---|
| [BR-loan-004@v1](../rules/BR-loan-004@v1.md) | constraint | ผู้สมัครต้องผ่านคุณสมบัติครบทั้งสามข้อ: อายุ 20–60 ปี · รายได้ต่อเดือน ≥ 15,000 บาท · อายุงานปัจจุบัน ≥ 4 เดือน · ผิดข้อใดข้อหนึ่งได้ Band C พร้อมเหตุผล | 🔴 0 |
| [BR-loan-005@v1](../rules/BR-loan-005@v1.md) | constraint | อัตราส่วนภาระหนี้ต่อรายได้หลังรวมค่างวดใหม่ต้อง ≤ 70% ของรายได้ต่อเดือน โดย DTI = (ภาระหนี้เดิมต่อเดือน + ค่างวดใหม่) / รายได้ต่อเดือน · DTI > 70% ได้ Band C | 🔴 0 |
| [BR-loan-006@v1](../rules/BR-loan-006@v1.md) | calculation | วงเงินอนุมัติสูงสุดของผู้สมัคร = ค่าที่น้อยกว่าระหว่าง 5 เท่าของรายได้ต่อเดือน กับ 1,000,000 บาท · จำนวนเงินกู้ที่ขอเกินวงเงินนี้ถือว่าผิดเกณฑ์ และได้ Band C | 🔴 0 |
| [BR-loan-007@v1](../rules/BR-loan-007@v1.md) | policy | จัดระดับเครดิตจากผลการประเมิน: Band A = ผ่านทุกเกณฑ์และ DTI ≤ 50% · Band B = ผ่านทุกเกณฑ์และ DTI มากกว่า 50% ถึง ≤ 70% · Band C = ผิดเกณฑ์ข้อใดข้อหนึ่ง (คุณสมบัติ BR-loan-004@v1 หรือ DTI BR-loan-005@v1 หรือขอเกินวงเงิน BR-loan-006@v1) ให้ปฏิเสธพร้อมเหตุผล · ที่ DTI = 50% พอดี ได้ Band A | 🔴 0 |
| [BR-loan-008@v1](../rules/BR-loan-008@v1.md) | policy | เมื่อใบสมัครถูกยื่น ระบบสร้าง CreditAssessment ที่มีคะแนน ระดับเครดิต (A/B/C) วงเงินที่อนุมัติได้ และเหตุผลรายเกณฑ์ · ใบที่ได้ Band A หรือ Band B เปลี่ยนสถานะเป็น UnderReview เหมือนกันทั้งคู่ และให้เจ้าหน้าที่เป็นผู้อนุมัติเสมอ (ไม่มีการอนุมัติอัตโนมัติ) | 🔴 0 |
