# BR-loan-027@v1

## ข้อความของกฎ
ใบสมัครที่เข้าสถานะ UnderReview เข้าคิวใบสมัครรอพิจารณาเป็นค่าเริ่มต้น โดยยังไม่ผูกกับเจ้าหน้าที่คนใด · Loan Officer หยิบใบจากคิวมาเป็นผู้รับผิดชอบของตัวเองได้เอง (self-assign) และเปลี่ยนมือมอบหมายใหม่ทีหลังได้ · การเข้าสถานะ UnderReview ต้องไม่ถูกบล็อกเพราะยังไม่มีผู้รับผิดชอบ

## ที่มา

> "ใบสมัครที่เข้าสถานะ UnderReview แต่ยังไม่ถูกมอบหมายให้เจ้าหน้าที่คนใด มีค่าเริ่มต้นให้ แล้วมอบหมายทีหลังได้"
> — [SRC-003](../sources/SRC-003.md) หน้า — §QB-apr-02

> "Loan Officer หยิบใบจากคิวกลางมาเป็นของตัวเองได้เอง (self-assign)"
> — [SRC-003](../sources/SRC-003.md) หน้า — §คำถามนอกคลัง — ใครมอบหมายและตอนไหน
