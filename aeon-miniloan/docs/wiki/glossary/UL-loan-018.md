# UL-loan-018

## นิยาม
ดอกเบี้ยที่เกิดขึ้นแล้วถึงวันที่ปิดบัญชี แต่ยังไม่ถึงกำหนดชำระตามตารางผ่อน · **เป็นส่วนหนึ่งของดอกเบี้ยรายงวด (UL-loan-020) ของงวดที่กำลังเดินอยู่ ไม่ใช่คนละตัว** — คือช่วงที่เดินไปแล้วของงวดปัจจุบัน ส่วนดอกเบี้ยของงวดในอนาคตไม่คิดเลย · ฐานการคิด (รายวันหรือรายงวด) ยังไม่ตกลง ต้องพินด้วย `/req:calc`
