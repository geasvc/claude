# UL-loan-021

## นิยาม
การผูกใบสมัครหนึ่งใบเข้ากับเจ้าหน้าที่ผู้รับผิดชอบหลักหนึ่งคน และผู้สำรองของใบนั้น · **แนวคิดนี้ไม่มีอยู่ในเอกสารต้นทางเลย** เกิดจากคำตอบ QB-perm-02 ใน `/req:ask permission` — ใครเป็นคนมอบหมาย มอบหมายเมื่อไร และถ้ายังไม่มอบหมายจะเกิดอะไร ยังไม่มีใครตอบ
