# CHG-job-001

## ทำไมถึงเปลี่ยน
TOR §3.5 ระบุชัดว่าค่าใช้จ่ายที่บันทึกหลังงานปิดต้องผ่านการอนุมัติก่อนจึงมีผล — คำบอกเล่าตอนแรก (SRC-001) หลวมกว่าเอกสาร จึงยกกฎขึ้นเวอร์ชันแทนที่จะแก้ทับ

| มีผลตั้งแต่ | 2026-08-01 |
| เอกสารที่ทำให้เปลี่ยน | [SRC-002](../sources/SRC-002.md) |
