# EX-job-035

## กำหนดให้ (given)
งาน J-1003 ค่าบริการพื้นฐาน 300 บาท ระยะทาง 51 กิโลเมตร (ขอบล่างของช่วง 51-60)

## เมื่อ (when)
ระบบคำนวณยอดรวมของงาน

## แล้ว (then)
ยอดรวมเป็น 450.00 บาท และหน้ารายละเอียดแสดง 'ค่าบริการ 300.00 + ค่าส่วนเพิ่มระยะทาง 150.00 = 450.00'
