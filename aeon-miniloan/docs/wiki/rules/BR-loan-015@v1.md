# BR-loan-015@v1

## ข้อความของกฎ
อัตราดอกเบี้ยเป็นแบบลดต้นลดดอก 25% ต่อปี และอัตราต่อเดือน r = อัตราต่อปี ÷ 12

## ที่มา

> "อัตราดอกเบี้ย: แบบลดต้นลดดอก 25% ต่อปี (สมมติ ภายใต้เพดานที่กฎหมายกำหนด)"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§5 BR-04 เงื่อนไขสินเชื่อ

> "`P` = เงินต้น, `r` = อัตราดอกเบี้ยต่อเดือน (= อัตราต่อปี / 12), `n` = จำนวนงวด"
> — [SRC-001](../sources/SRC-001.md) หน้า — §§5 BR-06 การคำนวณงวดผ่อน
