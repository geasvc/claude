# ขอบเขตงาน (ตัวอย่าง) — ระบบจัดการงานขนส่ง

## 3.2 การเดินสถานะงาน

งานขนส่งเดินตามลำดับ INIT → ASSIGN → LOAD → UNLOAD → COMPLETE

ผู้ดูแลระบบสามารถย้อนสถานะงานกลับได้ โดยต้องระบุเหตุผลทุกครั้ง
พนักงานขับรถไม่มีสิทธิ์ย้อนสถานะ

## 3.5 ค่าใช้จ่ายของงาน

ค่าใช้จ่ายที่บันทึกหลังงานปิด (COMPLETE) ต้องผ่านการอนุมัติก่อนจึงมีผล
