ต้องการให้ออกแบบ mockup plugin  สำหรับออกแบบหน้าจอ

  - handoff จาก claude design ได้ ถ้าไม่มี handoff ให้ถามก่อนว่าจะใช้ claude design หรือไม่ และแนะนำ prompt สำหรับสร้าง theme สำหรับ web 
  - ออกแบบ wireframe ตาม sitemap  ไม่ต้องเขียนเกี่ยวกับ design css เนื่องจากจะใช้จาก handoff หรือ theme template
  - ออกแบบ html ตาม sitemap ใช้ css จาก handoff ถ้าไม่มีให้ถาม
  - ตรวจสอบหน้า sitemap และเลือกสร้างหน้า mockup ได้
  - ส่งต่อ ให้ dev plugin อย่างไร 
  - ต้องเชื่อมโยงข้อมูล ตรวจสอบย้อนกลับ และ รู้ว่าหน้าเวป  มาจาก req ,design , code ,qa 
  - ต้องมี help command
